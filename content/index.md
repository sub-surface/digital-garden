# What's on my mind

**14/06/2026**
- There's a few things i'd still like to improve with the site 
	- I think the music player should display the track cover on a vinyl record and spin while playing. It may also be worth letting the music player pop-out into a separate window, so that it can sit in the background while browsing the whole internet.
	- I'd also like to add a "random note" button, which would take you to a random note in the garden. This could be a fun way to explore the site and discover new content.
	- More algorithmic and generative art, some of which may be folded into backgrounds, and some of which may be interactive. I think it would be interesting to have a section of the site dedicated to generative art, where users can create their own pieces and share them with others.

- I'd also like to start publishing some of my [[HeXO Theory]] looking at the game of infinite connect-6 on a hexagonal board. This is a game that I've been playing for a while, and I think it has some interesting mathematical properties that are worth exploring. I plan to write a series of notes on the theory behind the game, as well as some strategies for playing it. I've been working on many scattered bots at the [github](https://github.com/sub-surface/hexo-theory)
- Someone in the discord seemed to show it was NP-hard by constructing a reduction from 3-SAT, but I haven't seen a formal proof yet. I think it would be interesting to explore this further and see if we can come up with a more rigorous proof of the game's complexity.
- I'd also like to get a super lightweight bot running on the HeXO page, which can play the game against users. This would be a fun way to test out different strategies and see how they perform against a computer opponent. I think it would also be interesting to have a leaderboard for the best players, so that users can compete against each other and see who comes out on top. We'd probably have to make the hexgo page a bit more interactive, with a better UI and some visual feedback for the players. This could be a fun project to work on, and I think it would be a great addition to the site.

- In terms of my writing, I had an idea about the connection between philosophy and computation, and how the two fields can inform each other. I think there's a lot of potential for exploring the philosophical implications of computational systems, and how they can shape our understanding of the world. I plan to write a series of notes on this topic, looking at different aspects of computation and how they relate to philosophical concepts. This would mainly be in the context of analytic approaches but im hoping to look into deleuze's unfinished work on set theory to see if there are any interesting connections to be made. I think this could be a really interesting area of exploration, and I'm excited to see where it leads.
