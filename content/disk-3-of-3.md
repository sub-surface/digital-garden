So you did open it.

---

```
SUBSURFACES SETUP — Disk 3 of 3

Finishing installation ...

  Writing registry entries ........ done
  Registering file types .......... done
  Creating program group .......... done
  Removing temporary files ........ done

Setup is complete.

                              [ Finish ]
```

That's it. That is the whole disk.

Disk 3 is four kilobytes of housekeeping. No content, no code, nothing you could not live without. Its entire job is to go back over what the first two disks did and **declare it finished** — tidy the temporary files, write the last entry, and put a program group in the menu so that later, when you have forgotten all of this, there is a way back in.

Everybody assumes the last disk is the payload. The last disk is never the payload. The last disk is the part that says *this is done now, you may stop thinking about it.*

---

## Which is why losing it is the bad one

Lose disk 1 and you can infer the setup from what got installed.
Lose disk 2 and you have lost content — real, painful, but *nameable*. You know the shape of the hole.

Lose disk 3 and nothing is missing. Every file is present. The program is entirely there and entirely functional and it will run for another twenty years.

It just never got marked as finished. So it sits in the temp directory forever, one step from complete, and every time you come across it you have to work out from scratch whether it needs anything from you. Not because it does. Because nothing ever told you it didn't.

That is what I have actually been avoiding for a year, and it took writing it down to see it, which is the entire argument for writing things down.

---

## Setup is complete

The install worked. It has been working the whole time. The photographs are in the cupboard, the disks are in the box, the notes are in the garden, and none of it needs anything further from anyone.

You can stop checking.

> **Volume label:** `PERSISTENCE`
> The machine takes it at [os.subsurfaces.net/?seed=PERSISTENCE](https://os.subsurfaces.net/?seed=PERSISTENCE), and it will boot the same way every time, for as long as there is a machine.
>
> That is not a promise that anyone will run it. It is a smaller thing: that if someone does, it will still work.
>
> A garden is [[readme-1st|someone caring, currently]]. The disk only ever had to survive until the next person who cared. It did.

`[ Finish ]`
